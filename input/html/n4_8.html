メニューは、ABCD の 4 種類しゅるいから選えらべます。

カレーの種類しゅるいは下したの①、②のグループから選えらべます。

A メニュー 850 円えん
カレー ＋ サラダ　か　飲のみ物もの
（カレーは、①グループから選えらんでください。）
B メニュー 950 円えん
カレー ＋ サラダ　か　飲のみ物もの
（カレーは、②グループから選えらんでください。）
C メニュー 1100 円えん
カレー ＋ スープ ＋ サラダ ＋ 飲のみ物もの
（カレーは、①グループと②グループのどちらからでも選えらべます。）

カレー ＋ スープ ＋ サラダ ＋ 飲のみ物もの ＋ アイスクリーム
（カレーは、①グループと②グループのどちらからでも選えらべます。）

①グループ：たまごカレー、野菜やさいカレー、チキンカレー

②グループ：ハンバーグカレー、えびカレー

飲のみ物ものの種類しゅるい

コーヒー、紅茶こうちゃ、オレンジジュース

（コーヒーと紅茶こうちゃは、温あたたかいものと冷つめたいものがご用意よういできます。）
